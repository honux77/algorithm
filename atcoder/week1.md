# 알고리즘 문제풀이 재활 훈련

## 목표

AtCoder ABC 기준 A~B 문제를 빠르고 안정적으로 풀고, C 문제에 첫 도전한다.

## 일정

| 회차 | 날짜 | 시간 | 목표 |
|------|------|------|------|
| 1회 | 5/15 (목) | 30분 | 환경 점검 + ABC A 2문제 |
| 2회 | 5/16 (금) | 30분 | ABC B 2문제 |
| 3회 | 5/17 (토) | 1시간 | ABC B 복습 + C 1문제 도전 |
| 4회 | 5/19 (월) | 30분 | ABC B~C 1문제 |
| 5회 | 5/20 (화) | 30분 | 주간 복습 + 틀린 문제 다시 풀기 |

---

## Day 1 (5/15 목) — 환경 점검 + A 레벨 워밍업

**목표:** 손 풀기. 제출 환경 확인, A 레벨 2문제 풀기

- [X] 언어/편집기 세팅 확인 (Python or Java 결정)
- [X] ABC 최근 2회분 A 문제 각 1문제 풀기
- [X] 풀이 시간 기록 (목표: 문제당 5분 이내)

**참고:** ABC A 문제는 보통 사칙연산·조건문 수준. 막히면 재활 중이니 정상.

---

## Day 2 (5/16 금) — B 레벨 진입

**목표:** B 레벨 문제 2개 풀기

- [ ] ABC B 문제 2개 (난이도 200~400)
- [ ] 못 풀면 30분 후 editorial 확인 — 죄책감 없이
- [ ] 풀이 패턴 메모 (반복문, 정렬, 문자열 등)

---

## Day 3 (5/17 토) — B 복습 + C 첫 도전 (1시간)

**목표:** B 레벨 확실히 굳히기, C 레벨 한 문제 시도

- [ ] B 문제 2개 (시간 측정해서 20분 이내 목표)
- [ ] C 문제 1개 (30분 타이머, 못 풀어도 OK — 유형 파악이 목적)
- [ ] C 문제 editorial 읽고 접근법 이해

---

## Day 4 (5/19 월) — C 레벨 재도전

**목표:** 토요일 C 문제 유형과 비슷한 문제 1개 재도전

- [ ] 지난 C 문제 다시 풀기 (editorial 없이)
- [ ] 또는 비슷한 유형의 다른 C 문제 1개

---

## Day 5 (5/20 화) — 주간 복습

**목표:** 이번 주 틀리거나 막혔던 문제 정리

- [ ] 못 푼 문제 다시 한 번 풀어보기
- [ ] 자주 막힌 패턴 노트에 정리 (다음 주 집중 학습 주제 결정)

---

## 주간 목표 정리

- A 문제: 5분 이내 안정적으로 풀기
- B 문제: 20분 이내 목표
- C 문제: 유형 파악 + editorial 이해

## 사용 언어

- **Python**: 빠른 프로토타이핑, 문자열/수학 문제
- **C++**: 시간 복잡도 빡빡한 문제 (주로 C 레벨 이상)
- 1주차는 Python 위주로 풀고, C++ 환경도 병행 점검

## 메모

> 막혀도 괜찮다. 30분 고민했으면 editorial 봐도 된다.  
> 이번 주는 속도보다 **감 되찾기**가 목적.
