## Python 환경 설정

### venv 생성 및 적용

```bash
# venv 생성
python3 -m venv venv

# 활성화 (macOS/Linux)
source venv/bin/activate

# 활성화 (Windows)
venv\Scripts\activate

# 비활성화
deactivate
```
